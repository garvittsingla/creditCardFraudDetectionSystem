## 🚀 About the Project

Credit card fraud is a critical challenge in the financial industry, where fraudulent transactions are rare yet extremely costly. This project builds an end-to-end **ML-powered fraud detection system** that leverages advanced preprocessing techniques — including **RobustScaling**, **mutual information-based feature selection**, and **stratified sampling** — to identify fraudulent transactions with high precision. The entire workflow is designed for reproducibility and runs seamlessly on **Google Colab**.
